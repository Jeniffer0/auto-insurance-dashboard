# Auto Insurance Dashboard

## Overview

An interactive Microsoft Power BI project exploring an auto insurance dataset sourced from Kaggle. The dashboard provides visual summaries and interactive filters to support data exploration and the analysis of insurance-related information.

This project demonstrates my developing skills in business intelligence, data preparation, data visualisation, and insurance analytics.

## Tools and Technologies

- **Microsoft Power BI:** Dashboard development and data visualisation
- **Power Query:** Data preparation, transformation, and custom column creation
- **DAX:** Measures and analytical calculations
- **Kaggle:** Auto insurance dataset source

## Dashboard Features

- Interactive visual summaries of auto insurance data
- Charts, cards, and filters for exploring the dataset
- Interactive slicers for filtering and comparing data
- Data transformations and custom columns developed in Power Query

## Data Source

The project uses an auto insurance dataset obtained from Kaggle.

The dataset source, data dictionary, and relevant data-cleaning and transformation steps are being documented as part of the project.

## Data Preparation and Analysis

Data preparation and dashboard development involve working with Power Query to transform the dataset and create custom columns. Further documentation will describe the data structure, cleaning decisions, and analytical calculations used in the dashboard.

## How to View the Dashboard

1. Download the `.pbix` file from this repository.
2. Open the file using Microsoft Power BI Desktop.
3. Explore the dashboard using its visualisations, filters, and slicers.
